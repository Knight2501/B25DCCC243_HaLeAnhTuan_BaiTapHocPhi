# Bài tập Lập trình hướng đối tượng – Quản lý học phí sinh viên

## Thông tin sinh viên
- Họ tên: Hà Lê Anh Tuấn
- Mã sinh viên: B25DCCC243
- Lớp: INT1332-20261-18
- Học phần: INT1332 (20261-18)

## Cấu trúc thư mục
| Thư mục | Nội dung |
|---------|----------|
| Bai-1/  | Câu 1 – Chuẩn hóa thông tin sinh viên |
| Bai-2/  | Câu 2 – Tính học phí theo hệ đào tạo |
| Bai-3/  | Câu 3 – Quản lý danh sách học phí, ngoại lệ |
| Bai-4/  | Câu 4 – Miễn giảm học phí và thống kê theo hệ |

Mỗi thư mục chứa một file `Main.java` (không khai báo package).

## Hướng dẫn chạy
Yêu cầu: JDK 11 trở lên.

Ví dụ chạy câu 1:

    cd Bai-1
    javac Main.java
    java Main

Chương trình đọc dữ liệu từ bàn phím (System.in) theo định dạng trong đề.
Có thể nhập từ file:

    java Main < input.txt

Các câu khác chạy tương tự(Bai-2, Bai-3, Bai-4).
